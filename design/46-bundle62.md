**SqlTables**
1. **토큰** — `tokens`: `[` … `]` 를 `"`·백틱과 같은 식별자 토큰으로(안쪽 trim·대문자, 빈 것은 `[`) · `"`·백틱 안 **겹친 따옴표(`""`)는 이스케이프**(하나로 접어 계속). `;` 는 그대로 한 글자. 버린 대안 — `[`·`]` 를 단어 글자에 넣기(`[1,2]` 배열이 단어가 된다).
2. **첫 동사는 깊이 0 에서** — `firstVerb(t, from)`: `from` 부터 괄호 깊이를 세며 깊이 0 의 첫 `VERBS` 단어(없으면 null). `WITH … INSERT INTO t2` 가 INSERT, `COPY … FROM stdin`·`\copy (SELECT …)` 는 null → `tagVerb`. `tagVerb` 불일치 판정은 첫 문장만.
3. **CTE 이름** — `cteNames(t)` 선행 훑기: 모든 `WITH` 자리에서 `[RECURSIVE] 이름 [(열…)] AS [NOT] [MATERIALIZED] ( … ) [, 이름 …]*` 꼴이 **완전히** 맞을 때만 이름을 모은다(`matchingParen(t, i)` 토큰 짝). `WITH (NOLOCK)`·`WITH ORDINALITY AS a(…)`·`WITH CHECK OPTION`·`START WITH x = 1` 은 안 모인다. 끝에 `refs` 에서 CTE 이름을 뺀다(sqlfluff 정답과 같은 뜻 — CTE 와 같은 이름의 실제 표가 같은 문장에 있으면 같이 빠진다, 드물다 — 「드러난 것」 한 줄).
4. **괄호 켜기** — 깊이별 `on` 스택(`boolean` 리스트, 바닥 = `verb != null`). `(` push false · `)` pop(바닥은 안 뺀다) · 깊이 0 의 `VERBS` 단어 → 바닥 true · 괄호 안 `SELECT` → 그 층 true. **`opener` 는 그 층이 켜졌을 때만** 묻는다 → `EXTRACT(day FROM x)`·`SUBSTRING(x FROM 2)`·`CONVERT(x USING y)`·`JSON_TABLE(… PATH …)` 안은 닫힘, `IN (SELECT … FROM t)`·`EXISTS (SELECT …)`·`FROM (SELECT …)` 는 켜짐. 바닥이 꺼진 문장(`COPY`)은 아무 표도 안 센다. 더해서 앞 토큰이 `DISTINCT` 면 `FROM` 은 opener 가 아니다(`IS [NOT] DISTINCT FROM`).
5. **문장 경계** — 깊이 0 의 `;` 또는 단독 단어 `GO` → `verb = firstVerb(t, i + 1)` · `targetDone = false` · `st = CLOSED` · `table = false` · `pending = R` · 스택을 바닥만 남기고 `on = verb != null`. refs 는 문장 사이에 합친다(한 문장 = 한 매퍼 id).
6. **대상 동사** — `opener` 에 `MERGE`(verb MERGE·첫 번째 → C·U) 와 `APPLY`(→ R) 추가. TABLE 상태가 건너뛰는 말 `SKIP = {TABLE, ONLY, INTO, LOW_PRIORITY, QUICK, IGNORE, DELAYED, HIGH_PRIORITY, TEMP, TEMPORARY}`(`IGNORE` 는 `STOP` 에서 뺀다 — `DELETE IGNORE FROM t` 의 FROM 이 대상 그대로 이어지게). `INTO` 는 `MERGE INTO t` 에서 MERGE 가 먼저 열고 INTO 가 TABLE 상태로 떨어질 때 건너뛰는 자리(INSERT 의 INTO 는 여전히 opener). `SELECT … INTO x` 는 **안 잡는다**(사용자 결정). 버린 대안 — `DELETE` 대상을 다시 여는 `targetDone` 완화(문장 경계로 충분).
7. **TABLE 상태의 식별자** — ① 앞의 `.` 토큰들은 건너뛴다(`..[#t]`) ② 이름 사슬은 연속 `.` 를 허용(`a..b` → B) ③ **표 함수**: 단어 뒤 토큰이 `(` 이고 문맥이 R(`pending == {R}`)이면 함수 — 안 센다, `st = CLOSED`(이어서 `(` 가 꺼진 층을 연다). 예외: `(` 다음 단어가 잠금 힌트(`NOLOCK`·`READUNCOMMITTED`·`READPAST`·`ROWLOCK`·`UPDLOCK`·`HOLDLOCK`·`TABLOCK`·`TABLOCKX`·`XLOCK`·`NOWAIT`·`INDEX`·`FORCESEEK`)면 표 + 힌트(`FROM T (NOLOCK)`). C·U·D 문맥의 `INSERT INTO t (a, b)` 는 그대로 표 ④ **괄호 친 표**: TABLE 상태에서 `(` 다음 토큰이 단어이고 `SELECT`·`WITH`·`VALUES`·`BRANCH` 가 아니면 `(` 를 먹고 TABLE 상태 유지(`FROM (my_table tt)`·`JOIN (tbl_b b ON …)`), 아니면 지금처럼 CLOSED.
8. **복잡도** — `extract` 안에 분기를 더하지 말고 도우미로: `firstVerb`·`cteNames`·`matchingParen`·`boundary(…)`·`isFunction(t, i, pending)`·`skipDots`·작은 상태 홀더(`Scan` — on 스택·verb·targetDone·st·table·pending 필드와 `reset(verb)`). 각 도우미 복잡도 ≤ 15·중첩 ≤ 4·인자 ≤ 7. `extract`·`tokens` 의 기준선 줄 숫자는 바뀌어도 된다(함정 ①).

**DdlReader**
9. **CREATE 머리** — `CREATE`·`BURIED_CREATE` 정규식에 `(?:PRIVATE\s+)?` 를 `GLOBAL|LOCAL` 자리 옆에. 이름 글자 `NAME` 은 이미 `$` 를 허용(`ora$ptt_emp`).
10. **이름만 있는 표** — `read` 에서 `head` 가 참이면 `open` 계산 **앞에** `rest = stmt.substring(m.end())` 로 ① `partitionOf(rest)`: 첫 이름 토큰 뒤 낱말 둘이 `PARTITION OF` ② `ctas(rest)`: 첫 이름 토큰 뒤 첫 낱말이 `AS`·`SELECT`·`WITH` 이거나 `rest` 어딘가에 `(?i)\bAS\s*\(*\s*(SELECT|WITH)\b` 가 있으면(`NOLOGGING AS SELECT`·`STORAGE (…) AS SELECT`·`ON COMMIT PRESERVE ROWS AS SELECT`·Oracle `t (c1, c2) AS SELECT` 포함 — 일반 CREATE 의 컬럼 목록엔 `AS SELECT`·`AS (WITH` 가 못 온다) → `Draft(schema, name)` 만 만들고 `d.notes.put("ctas", "AS SELECT — 컬럼을 못 읽는다")`/`("partition", "PARTITION OF 부모 — 컬럼은 부모 표")` → `tables.put` → `continue`. 첫 이름 토큰은 `openParen` 의 따옴표·대괄호 규칙을 따르는 새 도우미 `firstName(rest)`(공백·`(`·`AS` 앞까지, 따옴표 안 공백 허용) → `nameParts`. 사용자 결정 — `tables()` 에 싣는다(컬럼 0).
11. **`;` 없는 연속 CREATE** — `statements()` 가 자른 조각마다 `splitCreates(stmt)`: 괄호·따옴표 밖 줄머리 `CREATE\s` 자리(`BURIED_CREATE` 와 같은 꼴)에서 가르되 **그 앞 조각에 이미 `CREATE.lookingAt()` 머리가 있을 때만**(첫 조각의 머리가 CREATE 가 아니면 — `;s\nCREATE TABLE` — 안 가른다 → 지금처럼 `unreadable`). 버린 대안 — `GO` 전제(파일에 GO 가 없다) · 항상 가르기(eGov PG 오타가 조용히 사라진다).
12. `read`·`item` 기준선 줄 숫자 변동 허용(함정 ①). 새 도우미 ≤ 15.

**JavaGraph**
13. **타입 변수 묶음** — `Cls` 에 `List<String> typeParams`(`t.getTypeParameters()` 이름) · `List<String> superArgs`(`extends X<A, B>` 의 인자를 `simple(Type)` 으로 — 없으면 빈 목록). `bindFor(Cls start, Map<String, Cls> startBind, Cls owner)`: `cur = start`, `bind = startBind`; `cur != owner` 인 동안 `up = lookup(cur, cur.superName)` 첫 것, `args = cur.superArgs` 를 `bind.get(arg)`(타입 변수면) 또는 `lookup(cur, arg)` 가 **하나**일 때 그 `Cls` 로 바꿔 `up.typeParams` 와 자리로 짝지어 새 bind(못 푼 자리는 빠진다), `cur = up`(`seen`·12 단 상한). `owner` 에 못 닿으면 빈 맵. 버린 대안 — 심볼 해석기 도입(6-3 결정 「이름으로 푼다」 유지) · `D` 를 `naming` 프로필로(프로젝트마다 다르다).
