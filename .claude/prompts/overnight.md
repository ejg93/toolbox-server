# 밤 번들 — 자는 동안 무인으로 번들을 잇는 프롬프트

설계 행이 이미 적힌 번들을 **사람 없이 연달아** 칠 때의 여는 말이다. ProjectShop `.claude/prompts/overnight.md` 를 이 저장소에 맞췄다(2026-09-26).
규칙 본문은 `CLAUDE.md` 「번들 모드」·「마무리」가 든다. 여기 있는 것은 밤에만 다른 것뿐이다.

## 자기 전에 사람이 하는 것

| 무엇 | 왜 |
|---|---|
| 플러그를 꽂고 절전을 끈다 | 잠들면 세션이 그 자리에서 선다 |
| Docker Desktop 을 켜 둔다 | 번들 1 뒤쪽부터 컨테이너 테스트가 돈다. `scripts/docker-up.sh` 가 켜 주지만 3분 기다린다 |
| `cd C:\workspace\toolbox-server` 에서 세션을 연다 | 훅의 `CLAUDE_PROJECT_DIR` 가 세션이 열릴 때 굳는다. portfolio 에서 열면 훅이 안 돈다 |
| `/model` 로 Opus | 설계는 Fable, 실행은 Opus |
| 아래 블록을 붙여넣고 마지막 줄의 토큰 비율을 채운다 | 안 적으면 규칙상 청크 하나만 치고 멈춘다 |

토큰 5시간 창이 차면 세션이 서고 스스로 다시 시작하지 않는다. 청크 하나 = 커밋 하나라 선 자리는 깨끗하다 — 아침에 「번들 해」 한마디가 「현재 상태」·이력 마지막 줄에서 잇는다. 페이스 실측(ProjectShop)은 8행 + 마무리 ≈ 2시간 10분.

## 붙여넣는 것

```
밤 번들이다. CLAUDE.md 「번들 모드」·「청크 규칙」·「마무리」를 읽고, PLAN.md 「번들」 표에서 상태 칸에
「밤 <오늘 날짜>」가 적힌 번들을 표의 순서대로 친다. PLAN.md 는 그 청크 행과 행이 가리키는 장만 읽는다. 통짜로 안 읽는다.

[먼저 확인]
1. git status 가 깨끗하고 가지가 work/* 인지. 아니면 멈추고 보고한다.
2. bash scripts/docker-up.sh — 안 뜨면 db 태그 행은 건너뛰고 이력에 적는다. 나머지 행은 친다.
3. 컨테이너 테스트가 있는 행은 첫 실행에서 이미지 pull 이 걸린다(mariadb·mssql·oracle-free 합계 약 4GB).
   pull 은 실패가 아니다 — 30분까지 기다린다. 넘으면 그 테스트를 @Disabled("이미지 pull 대기") 로 접고 이력에 적는다.

[청크마다]
- 그 행만 읽는다. 시작 세 줄(무엇을 닫나 / 걸리는 축 / 강제 지점)은 행에 있으니 확인만 한다.
- 번호 절차대로. 계획 밖 갈림은 실패 사다리 → 없으면 정하고 이력에 「정한 것(계획 밖)」.
  행당 둘까지. 셋째면 wip/<청크> 곁가지에 커밋하고 다음 행.
- bash scripts/verify.sh 가 빨가면 고치기 둘까지. 그래도면 wip/<청크> 로 빼고 다음 행.
- verify.sh 와 git commit 은 따로 낸다(훅이 명령 전에 잰다). 커밋 하나.
- PLAN 분할표 행의 상태 칸 → 완료(실제로 한 것·예보와 달라진 것), 번들 표 「k/n」, PROGRESS 이력 한 줄(직전 행 해시를 채운다).
- 청크 사이에 턴을 안 끝낸다. 보고는 한 줄이다.

[번들 끝 — CLAUDE.md 「마무리」 그대로, 여기서만 더하는 것]
- bash scripts/verify.sh --full 은 push 와 따로 낸다.
- push → gh pr create --base main(본문에 청크마다 시작 세 줄 표) → CI 를 gh api 로 폴링한다(gh pr checks 는 권한 분류기가 막는다).
- 독립 리뷰(Agent 로 git diff origin/main...HEAD 를 리뷰)의 지적은 전부 지금 고치거나 새 행으로. 오탐은 근거를 적는다.
- **머지를 맡겼다**: CI 전부 초록이고 리뷰 지적을 처분했으면 gh pr merge N --merge --delete-branch →
  git checkout main && git pull → 다음 가지 work/<날짜>-N → 다음 번들.
- CI 빨강은 고치기 둘까지. 그래도면 PR 을 열어 둔 채 멈추고 보고한다.

[멈추는 자리 — 여기서만 멈춘다]
- 번들 표의 밤 번들을 다 쳤다.
- 토큰이 20% 밑이다 — 진행중 청크가 있으면 wip/ 로 빼고 마무리까지 한다.
- CI 를 두 번 못 고쳤다.
- 행이 사람의 입력(설치·GitHub 설정 변경·라이선스 파일)을 요구한다 — 그 행은 접고 다음 행. 번들에 그런 행만 남으면 멈춘다.

[끝 보고 — 멈출 때]
PROGRESS 이력 마지막 줄 + 「현재 상태」 + 마지막 PR 본문에: 계획 밖 결정 전부 · wip/ 로 뺀 행과 이유 ·
새로 선 행 · 사람이 할 것. 아침에 볼 것 셋: main 마지막 커밋, gh pr list, git branch --list 'wip/*'.

토큰은 이번 5시간 창에 __% 남았다.
```

## 조항마다 무엇을 막나

| 조항 | 빼면 |
|---|---|
| 세션을 저장소 디렉터리에서 연다 | 훅이 다른 저장소를 본다. 커밋·push 검사가 조용히 빠진다 |
| pull 은 실패가 아니다 | 첫 컨테이너 테스트가 20분 걸리는 것을 「verify 빨강」으로 세고 wip/ 로 뺀다 |
| 계획 밖 갈림은 정하고 간다 | 밤에 「멈추고 묻는다」는 곧 정지다. 설계 세션이 이미 물었다 |
| `wip/<청크>` 로 뺀다 | 빨간 트리가 `work/*` 에 오르면 commit hook 이 막고 뒤 청크가 다 빨개진다 |
| 머지 위임을 글로 적는다 | 안 적으면 마무리가 PR 을 열고 멈춘다. 둘째 번들이 첫 PR 위에 쌓여 리뷰 diff 가 커진다 |
| CI 는 `gh api` 로 폴링 | `gh pr checks` 는 권한 분류기가 막고 폴링이 조용히 헛돈다 |
| 사람 입력이 필요한 행은 접는다 | Tibero 라이선스 같은 자리에서 밤새 기다린다 |
| 토큰 20% 에서 마무리 | 창이 차면 마무리 없이 선다 — 아침에 PR 없는 커밋 열 개를 사람이 정리한다 |
