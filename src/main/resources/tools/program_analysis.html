CSV 열 — 메뉴(경로 「대 > 중 > 소」, 깊이 제한 없음) · URL · 화면ID(선택) · 사용여부(선택, Y/N) · 권한(선택). 행 순서가 트리 순서다. 재귀는 SQL 에서 펼친다. 프로필마다 한 벌 — 다시 올리면 통째로 바꾼다. SQL 은 복사만 한다(DB 툴에서 돌려 CSV 로 저장).
egov 메뉴(Oracle — CONNECT BY)
-- egov 메뉴 → CSV(Oracle). 경로는 CONNECT BY, 순서는 ORDER SIBLINGS BY
SELECT LTRIM(SYS_CONNECT_BY_PATH(m.MENU_NM, ' > '), ' > ') AS "메뉴",
       p.URL AS "URL", NULL AS "화면ID", 'Y' AS "사용여부"
FROM   COMTNMENUINFO m LEFT JOIN COMTNPROGRMLIST p ON p.PROGRM_FILE_NM = m.PROGRM_FILE_NM
START WITH m.UPPER_MENU_NO = 0
CONNECT BY PRIOR m.MENU_NO = m.UPPER_MENU_NO
ORDER SIBLINGS BY m.MENU_ORDR;
자기 참조 메뉴 표(PostgreSQL·MySQL 8 — WITH RECURSIVE, 열 이름은 사업 표에 맞게)
-- 자기 참조 메뉴 표 → CSV. 경로는 위에서 아래로 이어 붙이고, 순서 키로 트리 순서를 만든다
WITH RECURSIVE t AS (
  SELECT menu_id, menu_nm AS path, url, use_yn, LPAD(CAST(sort_no AS CHAR(6)), 6, '0') AS ord
  FROM   menu WHERE parent_id IS NULL
  UNION ALL
  SELECT c.menu_id, CONCAT(t.path, ' > ', c.menu_nm), c.url, c.use_yn, CONCAT(t.ord, '.', LPAD(CAST(c.sort_no AS CHAR(6)), 6, '0'))
  FROM   menu c JOIN t ON c.parent_id = t.menu_id
)
SELECT path AS "메뉴", url AS "URL", use_yn AS "사용여부" FROM t ORDER BY ord;
