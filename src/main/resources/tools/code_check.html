폴더 폴더 단계
같은 프로필·같은 폴더(폴더 검사 탭의 폴더 칸)의 전체 검사 이력을 건수로 늘어놓는다 — 변경분 검사는 대상이 달라 뺀다. 고쳐짐·새로 생김은 파일·규칙 단위(줄 번호는 안 본다), 규칙 지문이 앞 실행과 다르면 「다름 ⚠」 이고 견주지 않는다
